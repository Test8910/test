MultiCam CNC Post

Convert CAM-neutral toolpath JSON into MultiCam JobServer and A2MC/AMC .cnc G-code.

  • classic — M90 / M12 / M22 / M02, absolute I/J
  • a2mc — non-modal Fanuc-style for AU Toolpath

Install and run from the repository:

pip install -e ".[dev]" && multicam-post multicam_post/examples/square.json --stdout
